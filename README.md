# bentwire

bentwire brings the animated desktop characters of Microsoft Agent and the Office
Assistant to the Linux Wayland desktop. A daemon, `bentwired`, shows one character above
your windows. It plays its animations, idles, speaks in a word balloon, asks questions in
an Office-style balloon and can be dragged, right-clicked and hidden. Programs and scripts
drive it over D-Bus or through the `bentwire` command line client. Shell and Claude Code
integrations are included.

bentwire reads the original character formats (Agent 2.0 ACS, ACF/ACA web characters,
Agent 1.5, Office 97 and Microsoft Bob ACT actors) and converts them into its own open
format (`docs/character-format.md`). The behaviour follows `docs/spec.md`, which is
derived from clean-room research of the original runtimes.

## Layout

| Path | What |
|---|---|
| `crates/agent-formats` | Parsers for ACS 2.0, ACF/ACA 2.0, Agent 1.5 (OLE ACS, ACF/AAF) and ACT |
| `crates/agent-fixtures` | Writers for synthetic test files (tests only) |
| `crates/bentwire-character` | Character format: manifest model, folder and `.bwc` reader and writer, compositor, validation, audio decoding |
| `crates/bentwire-convert` | Source formats to bentwire characters, WMF rasteriser, pack generators |
| `crates/bentwire-core` | Deterministic behaviour core (no I/O) |
| `crates/bentwire-render` | Software rendering: character buffers, Agent and Office balloons, menu, bundled Tahoma |
| `crates/bentwired` | The daemon: Wayland (layer shell) and headless backends, D-Bus API, tray, audio |
| `crates/bentwire` | The CLI |
| `clients/` | Shell (bash, zsh) and Claude Code integrations |
| `characters/builtin` | CC0 placeholder character, generated by code |
| `characters/classics` | Converted Microsoft characters and the Office balloon theme (see Licences) |
| `packaging/` | D-Bus activation file and optional systemd user unit |

`docs/architecture.md` describes the crates, file ownership and cross-cutting decisions.
`docs/desktop.md` covers the daemon on the desktop in more detail.

## Build and install on Arch Linux with KDE Plasma (Wayland)

Packages needed to build:

```sh
sudo pacman -S --needed rust wayland libxkbcommon alsa-lib pkgconf
```

At run time the daemon needs a session bus (dbus-broker or dbus-daemon; zbus is pure
Rust and needs no libdbus) and a compositor with `zwlr_layer_shell_v1`
version 4 or later (Plasma 6, sway, Hyprland). Without layer shell it exits with a
message. The tray icon needs a StatusNotifierItem host (Plasma's system tray).

Build and install for your user:

```sh
cargo build --release -p bentwired -p bentwire
install -Dm755 target/release/bentwired target/release/bentwire -t ~/.local/bin/

# Characters: copy (or symlink) the packs.
mkdir -p ~/.local/share/bentwire/characters
cp -r characters/builtin characters/classics ~/.local/share/bentwire/characters/

# D-Bus activation, so that `bentwire ...` starts the daemon on demand.
install -Dm644 packaging/dbus/org.bentwire.Agent.service -t ~/.local/share/dbus-1/services/
sed -i "s|^Exec=.*|Exec=$HOME/.local/bin/bentwired|" ~/.local/share/dbus-1/services/org.bentwire.Agent.service
```

Optional: start the daemon with the session instead of on demand.

```sh
install -Dm644 packaging/systemd/bentwired.service -t ~/.config/systemd/user/
sed -i "s|^ExecStart=.*|ExecStart=$HOME/.local/bin/bentwired|" ~/.config/systemd/user/bentwired.service
systemctl --user daemon-reload && systemctl --user enable --now bentwired
```

Characters are searched in these roots, in order: each entry of the config key
`character_paths`, `$XDG_DATA_HOME/bentwire` (normally `~/.local/share/bentwire`), then
each `$XDG_DATA_DIRS` entry plus `/bentwire`. Inside a root, `characters/` holds
characters (a folder with `character.toml`, or a `.bwc` file) and packs (a folder with
`pack.toml`). The first character with a given id wins. With only `builtin` installed,
the daemon shows `bentwire-placeholder`. With `classics` installed, the default is
`clippit`.

## Usage

```sh
bentwired &                    # or rely on D-Bus activation
bentwire show
bentwire play Writing
bentwire say "It looks like your build failed."
bentwire ask "Build failed." --button "Show log" --button "Ignore"
bentwire characters            # installed characters
bentwire select rocky
bentwire hide
```

Right-click the character for its menu: Hide, Options... (creates and opens the config
file), Choose Assistant... (a gallery balloon to browse and pick a character) and
Animate!. Drag it with the left or right mouse button. A left click on the tray icon
shows a hidden character; the tray icon's menu has the same items (Show while hidden).

### `bentwired` options

| Option | Meaning |
|---|---|
| `--characters DIR` | Prepend a character search root (repeatable) |
| `--no-tray` | Do not register a tray icon |
| `--no-audio` | Do not open an audio device |
| `--test-interface` | Export `org.bentwire.Test1` (`Pointer`, `Key`, `Snapshot`) on the Wayland backend |
| `--headless` | Headless backend with a fake clock (tests) |
| `--outputs WxH+X+Y[@S],...` | Virtual outputs in headless mode (default `1920x1080+0+0`) |
| `--seed N` / `--draws FILE` | Seed or scripted draws for the random source |
| `--trace FILE` | Headless: JSON lines of backend requests, sounds, signals and calls |
| `--dump-frames DIR` | Headless: a PNG of the composed scene per output whenever it changes |

`RUST_LOG=debug` gives more log output. The daemon owns the bus name
`org.bentwire.Agent`. A second instance exits with "already running". SIGTERM, SIGINT
and `bentwire quit` save the state and exit.

### CLI reference

The CLI is a thin D-Bus client. Without a running daemon it relies on D-Bus activation.
If that also fails, it prints `bentwired is not running` and exits 1. `bentwire help`
prints the usage.

| Command | Does | Output |
|---|---|---|
| `play <name> [--wait]` | Play an animation or state (missing names fall back by B-FB-1) | request id |
| `say <text> [--wait]` | Speak in the word balloon (`a\|b` picks one alternative; `\Mrk=n\` bookmarks) | request id |
| `ask [<text>] [--heading H] [--icon I] [--buttons SET \| --button CAPTION ...] [--label L ...] [--label-type T] [--checkbox C ...] [--mode M] [--animation NAME]` | Office balloon; always waits for the answer | line 1: the result; line 2 with check boxes: `checked:` and comma-separated 0/1 values |
| `moveto <x> <y> [--speed MS] [--wait]` | Slide to a position (default speed 1000) | request id |
| `gestureat <x> <y> [--wait]` | Gesture towards a point | request id |
| `show [--fast] [--wait]` | Show (animated unless `--fast`) | request id |
| `hide [--fast] [--wait]` | Hide | request id |
| `stop [<id>] [--all]` | Stop one request, the current one, or all (`--all`) | nothing |
| `characters` | List installed characters | `id<TAB>name` per line, the current one with a third column `*` |
| `select <id>` | Switch character | nothing |
| `animations` | Animation names of the current character | one per line |
| `status` | Properties | `character`, `visible`, `left`, `top`, `idle` as `key=value` lines |
| `quit` | Stop the daemon | nothing |
| `convert <source> <dest> [--palette FILE] [--lang TAG] [--codepage LABEL]` | Convert a character file locally, no daemon | nothing |

`--wait` blocks until the request completes.

`ask` details:

- `--icon`: `none`, `alert`, `tip`, `info`, `warning`, `query`, `critical`.
- `--buttons SET`: `none`, `ok` (default), `cancel`, `ok-cancel`, `yes-no`,
  `yes-no-cancel`, `back-close`, `next-close`, `back-next-close`, `retry-cancel`,
  `abort-retry-ignore`, `search-close`, `back-next-snooze`, `tips-options-close`,
  `yes-all-no-cancel`. `--button CAPTION` (1 to 6 times) gives custom buttons; `&` marks
  the mnemonic letter.
- `--label` up to 5 times, `--label-type` `buttons` (clickable, default), `bullets` or
  `numbers`. `--checkbox` up to 5 times.
- `--mode` `modal` (default) or `autodown`, which also closes on a click on the character
  or the balloon and on the next client request.
- `--animation` is played before the balloon (default `Explain`, `""` for none).
- Body text markup: `{cf n}` colour (0..7, 248..255), `{ul 1}` / `{ul 0}` underline.
- Result line: `ok`, `cancel`, `yes`, `no`, `back`, `next`, `retry`, `abort`, `ignore`,
  `search`, `snooze`, `close`, `tips`, `options`, `yes-to-all`; `button:<n>` for custom
  buttons (1-based); `label:<n>` for a clicked label; `none` if dismissed or interrupted.

Exit status: 0 success; 1 usage, D-Bus or method error (error name and message on
stderr); 2 the request failed (for `ask`: nothing is printed, the reason goes to stderr);
3 interrupted, or `ask` result `none`.

## Configuration

`~/.config/bentwire/config.toml` (`$XDG_CONFIG_HOME`). All keys are optional. The
menu's Options... writes a commented default file if none exists. Send `SIGHUP` to
`bentwired` to reload it. A file that fails to parse keeps the previous config, and
unknown keys are ignored.

| Key | Default | Meaning |
|---|---|---|
| `character` | unset | Character id to start with (after the state file) |
| `language` | `"auto"` | `auto`, `de` or `en` (menu, tray, balloon buttons, names); `auto` reads `LC_ALL`, `LC_MESSAGES`, `LANG` |
| `sound_effects` | `true` | Play character sounds |
| `balloon` | `true` | Show the word balloon for `say` |
| `balloon_font` | `""` | One font for every character's balloon; empty = each character's own |
| `speaking_speed` | `1.0` | Word pacing factor, 0.5 to 1.5 |
| `idle` | `true` | Idle animations on at start |
| `double_click_ms` | `500` | Double-click interval |
| `character_paths` | `[]` | Extra character search roots, searched first |

State (character, position, visibility) is kept in `~/.local/state/bentwire/state.toml`.

## Importing your own character files

```sh
bentwire convert MERLIN.ACS ~/.local/share/bentwire/characters/merlin.bwc
```

The format is detected from the file content. A destination ending in `.bwc` gives a
single package file; any other destination gives a folder. Supported sources:

| Source | Give `convert` | Notes |
|---|---|---|
| Agent 2.0 character (`.acs`) | the `.acs` | |
| Agent 2.0 web character (`.acf` + `.aca`) | the `.acf` | its `.aca` animation files must sit next to it (names matched case-insensitively); missing ones are listed, not invented |
| Agent 1.5 character (OLE `.acs`) | the `.acs` | damaged animation streams are reported per animation |
| Agent 1.5 web character (`.acf` + `.aaf`) | the `.acf` | as for 2.0 web characters |
| Office 97 / Microsoft Bob actor (`.act`), vector | the `.act` | rasterised at 1x and 2x |
| Office 97 / Microsoft Bob actor (`.act`), bitmap | the `.act` plus `--palette FILE` | the Office palette is read from an Office `.acs` file or `MSO97.DLL` |

For ACT actors, `--lang TAG` sets the language of the name (default `en`) and
`--codepage LABEL` the codepage of names and strings (default `windows-1252`; for example
`shift_jis` for Japanese actors). Conversion fails loudly on anything it cannot represent
instead of guessing. The converted character keeps its source file name and SHA-256 in
`[source]`.

To rebuild the whole `classics` pack from the original files, run
`characters/classics/regenerate.sh` (see `characters/classics/README.md`).

## Testing

```sh
cargo build --workspace
cargo test --workspace
cargo clippy --workspace --all-targets -- -D warnings
cargo fmt --check
```

Plain `cargo test` uses only synthetic characters and the bundled font. It includes the
renderer's golden images (`crates/bentwire-render/tests/golden`; regenerate with
`BENTWIRE_BLESS=1`) and the D-Bus end-to-end tests on a private bus
(`cargo test -p bentwired --test e2e`).

Real-data tests compare against the original files and the research oracle. They need
`BENTWIRE_REFERENCE=$BENTWIRE_REFERENCE` and `BENTWIRE_SOURCES=~/Sources/bentwire`:

```sh
cargo test --workspace -- --ignored      # or:
scripts/oracle-check.sh
```

With a variable unset, an ignored test fails with "NOT RUN", and `oracle-check.sh` prints
"NOT RUN" and exits 77. They never count as passed.

Desktop scenario (show, play, say, ask answered over D-Bus, moveto, hide, with signal and
screen checks). It also needs `dbus-run-session`, `busctl`, `python3` (with
`python-gobject` for the tray checks), `sway` and `grim`, or `kwin_wayland`:

```sh
cargo build -p bentwired -p bentwire && cargo build -p bentwired --examples
scripts/desktop/scenario.sh sway     # headless sway, screenshots with grim
scripts/desktop/scenario.sh kwin     # kwin_wayland --virtual
```

Under sway the script also checks a real virtual pointer (click, click-through, drag,
menu grab), output scales 2 and 1.5, output hot-plug and the tray against a minimal
StatusNotifierItem watcher. Screenshots are taken with grim and checked by colour and
position. Under KWin, screenshots are not possible on the build machine: KWin's
ScreenShot2 needs an OpenGL render node, and the VM has none. The character's geometry
is therefore read through KWin scripting (`workspace.windowList()`), and balloons and
menu through the backend's own record (`Test1.Snapshot`). The scale and hot-plug steps
run under sway only.

## Not verified headless (please check on Plasma)

Under headless sway a virtual pointer checked: a click on an opaque pixel, click-through
on a transparent one, a drag staying 1:1, and the right-click menu with a real popup
grab and its dismissal by an outside click. Under KWin these ran only through `Test1`.
Please check on Plasma:

- Negative margins and positions partly off the output (requested and recorded, not
  seen on screen under KWin).
- The character's layer below a full-screen window and above normal windows.
- Clicks, drags and the menu grab with a real mouse on KWin.
- Keyboard focus of the ask balloon after a real click (`on_demand` is requested and
  checked, the focus itself is not).
- The tray in Plasma's system tray (tested only against a minimal watcher: registration,
  Id, Title, menu labels, a menu click, Activate).
- Output hot-plug on KWin (tested on sway).
- Sound through a real audio device (headless runs log sounds with their duration).
- Pixels under KWin: no screenshot comparison was possible there.
- Fractional scale (1.5, through viewporter) and buffer scale 2: only the requests were
  checked, and sway accepted them. The 2x output pixels were not compared, and these
  steps did not run under KWin.
- Multi-monitor setups: covered only by a second headless output under sway and its
  removal.
- `hidpi` sheets on a real 2x output.
- Options... opening the config file through a real `xdg-open` handler (tested with a
  fake `xdg-open`, which shows that the file is written).
- The tray icon image as Plasma draws it (registration and properties were tested, not
  the picture).

## bentwire decisions

Where the research left a gap, the build chose a behaviour and recorded it in
`docs/spec.md` section 3.14 (spec T-7). The decisions taken while writing the spec
itself are marked **bentwire decision** in its sections 3.1 to 3.13.

| ID | Summary |
|---|---|
| A-PACK-1 | Packs (`pack.toml`) and search roots (`character_paths`, XDG dirs, `--characters`) |
| A-ID-1 | Unique character ids in `classics` (`clippit`; suffixes `-web`, `-15`, `-97`, `-bob`, `-act`) |
| A-PACK-2 | `classics` holds every source that converts with no missing animations |
| A-CHAR-1 | With only `builtin` installed, `bentwire-placeholder` is the default |
| A-THEME-1 | The Office balloon theme is pack data with a generic loader; the look-alike is the fallback |
| A-TEST-3 | `--test-interface` exports a reduced `Test1` on the Wayland backend |
| B-REN-1 | Text: advance-only, whole-pixel advances, OS/2 win metrics, cell versus em heights, fontconfig fallback |
| B-REN-2 | Look of the own Office balloon art: button states, check boxes, hot labels, alert icon |
| B-REN-3 | XP-style menu metrics and colours |
| B-REN-4 | HiDPI input shape: a logical pixel counts if any covered buffer pixel is opaque |
| B-REN-5 | Headless frame dumps: one transparent PNG per output, fixed z-order |
| B-REN-6 | Balloon outlines as GDI-style regions; the region is also the input region |
| B-REN-7 | Balloon theme file format (`theme.toml`, button strips, bullets, icons) |
| B-REN-8 | Office balloon font size is the Tahoma cell height (13 / 16 px) |
| A-FMT-1 | Parser memory and size limits against hostile input |
| A-FMT-2 | Strict record consumption and size checks in ACS, ACF, ACA/AAF |
| A-FMT-3 | Format edge cases without samples (image kind 0, raw images, mouth types, UTF-16) |
| A-FMT-4 | Agent 1.5 and web characters fail per animation, not per file |
| A-CORE-1 | Office balloon sizing constants (area terms, minimum size, shape choice) |
| A-CORE-2 | Office balloon controls: check-box rows, mnemonics, where markup applies, argument errors |
| A-CORE-3 | Small engine choices (interrupts, double-click, gallery, drags during slides, Animate! shuffle) |
| A-CORE-4 | office97 transition checks and per-callback frame caps |
| A-CORE-5 | Agent balloon tail position and pixel-step scrolling |
| A-CORE-6 | Exit runs end when they revisit a frame |
| A-CHAR-2 | Loader strictness: errors versus warnings, accepted PNG variants |
| A-CHAR-3 | HiDPI sheet choice per layer from the destination rectangle |
| A-CHAR-4 | Character sanity limits; oversized output composes to an empty picture |
| A-CONV-1 | Vector actors rasterised at 1x and 2x with their exact metafile colours |
| A-CONV-2 | Sounds deduplicated by PCM, ids `sNN` |
| A-CONV-3 | ACT language, codepage and Office palette are converter options |
| A-CONV-4 | Agent 1.5 files record no animation set version |
| A-THEME-2 | How the OBALLOON.DLL bitmaps become the theme's strips and icons |
| A-CONV-5 | Ids for file names with a parenthesised qualifier; identical sources converted once |
| A-CONV-6 | Out-of-range indices in source data mean no layer, no sound or transparent |
| A-PACK-3 | Fully transparent helper actors are excluded from `classics` |
| W-RAST-1 | WMF geometry: mapping mode, pixel-centre coverage, pen widths |
| W-RAST-2 | Ellipse and RoundRect pens |
| W-COL-1 | WMF colours map to the nearest palette entry |
| W-ROP-1 | ROP2 codes evaluated per channel on palette colours |
| W-TEXT-1 | WMF TextOut drawn with the bundled Tahoma |
| A-DESK-1 | `Ask` rejects unknown keys |
| A-DESK-2 | CLI details: `characters` marker column, `ask` exit codes, `convert` options |
| A-DESK-3 | `Test1` arguments and hit-testing |
| A-DESK-4 | Headless trace format and frame dump names |
| A-DESK-5 | Wayland details: applied-position tracking, fractional scale, balloon subsurfaces |
| A-DESK-6 | Daemon flags, config error handling, signals, tray mnemonics |
| A-ACT-1 | ACT parser strictness and the runtime leniencies it keeps |
